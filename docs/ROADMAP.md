# VillaguayConectado — Roadmap

## Visión

VillaguayConectado busca convertirse en la plataforma centralizada de eventos de la ciudad de Villaguay, permitiendo descubrir, administrar y compartir eventos de manera simple, moderna y accesible.

Este roadmap representa el estado actual del proyecto y las próximas etapas de desarrollo.

---

## Estado actual

**Fase:** MVP Universitario → Evolución hacia MVP Real

El proyecto ya cuenta con una arquitectura estable, una identidad visual definida y una base sólida para continuar incorporando funcionalidades.
